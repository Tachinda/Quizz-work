Absolutely. Let's take it slowly, as if you're just starting JavaScript. The good thing is that your quiz is a great example for learning JavaScript because it uses the most important beginner concepts: variables, loops, functions, events, conditions, and DOM manipulation.

Here is the code again:

const questions = document.querySelectorAll('.flex');

questions.forEach(question => {
    const buttons = question.querySelectorAll('.btn');

    buttons.forEach(button => {
        button.addEventListener('click', () => {

            buttons.forEach(btn => {
                btn.classList.remove('correct', 'wrong');
            });

            if (button.dataset.correct === "true") {
                button.classList.add('correct');
            } else {
                button.classList.add('wrong');
            }
        });
    });
});

document.querySelector('.sub').addEventListener('click', () => {
    let score = 0;

    questions.forEach(question => {
        const selected = question.querySelector('.btn.correct');

        if (selected) {
            score++;
        }
    });

    alert("Your mark is: " + score + " / " + questions.length);
});

The 6 things I recommend you learn from this code

Since you're a beginner, don't try to memorize everything. Focus on these six concepts:

const / let → storing information
querySelector() → finding HTML elements
forEach() → going through multiple elements
addEventListener() → reacting to user actions
if / else → making decisions
classList.add/remove() → changing CSS classes

Once you understand those six, you'll be able to build much more interesting JavaScript projects.
